# Словарик

Тренажёр словарного диктанта на русском языке: 261 слово для 1–4 классов, запоминание, тренировка и диктант. Можно составить занятие из слов разных классов; одинаковые слова задаются один раз. Прогресс и выбранные списки сохраняются в браузере на устройстве.

## Запуск

Это статический сайт без сборки, сервера приложений и API-ключей. Все файлы сайта находятся в `docs/`.

```sh
python3 -m http.server 8000 --directory docs
```

Откройте http://localhost:8000. Записи русского голоса входят в проект. Каждое слово записано отдельно; полная запись сохраняется без нарезки по слогам. Класс загружается одним аудиопакетом, который сохраняется в браузере; до готовности пакета доступна загрузка отдельной записи.

## GitHub Pages

1. Создайте репозиторий на GitHub.
2. Папка `docs/` содержит готовый сайт. Сохраните все подпапки, включая `audio/`.
3. Добавьте пустой файл `docs/.nojekyll`.
4. Загрузите файлы в ветку `master`.
5. Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **master** и папку **/docs**, затем **Save**.

В готовом архиве для GitHub папка `docs/` и `.nojekyll` уже подготовлены: загрузите содержимое архива в корень репозитория и выполните шаг 5. Для локального запуска используйте команду выше.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Изменение слов и звука

- `words.js` — школьные списки и принадлежность слов к классам.
- `audio-map.js` — путь к записи каждого слова.
- `audio-packs.js` — размер пакетов и границы MP3-файлов внутри них.
- `audio-cache.js` — предварительная загрузка и кэш записей.
- `app.js`, `index.html`, `styles.css` — логика и интерфейс.

Озвучка подготовлена русской моделью [Silero TTS v5_5_ru](https://github.com/snakers4/silero-models), голос `xenia`. В `audio-sources.json` отдельно хранятся правильное школьное написание и форма для синтеза с явно заданным ударением: `ос+ина`, `кап+уста`, `сап+ог`. Знак `+` стоит перед ударной гласной и не показывается ребёнку. Безударные гласные произносит русская модель; написание слов не заменяется фонетической транскрипцией.

Модель Silero распространяется с лицензией CC-BY-NC, согласно разделу лицензий проекта: https://github.com/snakers4/silero-models#licence. Сайт предназначен для некоммерческой подготовки к школьному диктанту. Модель не входит в архив сайта и не нужна для воспроизведения готовых MP3.

Для пересоздания записей установите PyTorch и NumPy, скачайте модель https://models.silero.ai/models/tts/ru/v5_5_ru.pt и выполните:

```sh
python3 scripts/generate_audio.py --model /путь/к/v5_5_ru.pt --output /путь/к/исходным/wav
```

При замене аудиозаписей нужно также пересобрать аудиопакеты и обновить их индекс. `audio-sources.json` описывает исходные записи, их имена и номер ревизии. Скрипт `scripts/build_audio.py` принимает каталог полных исходных WAV с именами `<id>.wav`, добавляет паузы и собирает пакеты; требуется установленный FFmpeg:

```sh
python3 scripts/build_audio.py --sources /путь/к/исходным/wav --output docs
```

Не разрезайте общую фразу по меткам распознавания речи: такая нарезка может терять слоги. Для нового слова сделайте отдельную запись и обновите описание источников. Если добавленное слово не имеет записи, взрослый может открыть его и прочитать вслух.

При новой ревизии измените также номер кэша и параметр `?v=` в `audio-cache.js`, чтобы устройства загрузили новый голос.

Проверка сохранения полной звуковой волны исходника: `python3 scripts/verify_audio.py --sources /путь/к/исходным/wav --assets docs` (требуется NumPy и FFmpeg). Эта проверка обнаруживает обрезание записи; качество произношения оценивают прослушиванием.
